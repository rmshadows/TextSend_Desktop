连接中
浏览器传文字、图片和文件。只在可信局域网用。中断可续传，单个最大 20GB。
安装证书 可选。点一下下载根证书，按手机提示安装并信任。

已经装进系统的根证书，网页删不掉。名称是 TextSend LAN CA。机型菜单可能略有不同，找到「受信任的凭据」或「描述文件」即可。

安卓：设置 → 安全和隐私 → 更多安全和隐私 → 加密与凭据 → 受信任的凭据 → 用户 → TextSend LAN CA → 移除。有的手机在「用户凭据」里。

iPhone：设置 → 通用 → VPN 与设备管理 → TextSend LAN CA → 移除描述文件。再到 设置 → 通用 → 关于本机 → 证书信任设置，确认它已经关掉。
